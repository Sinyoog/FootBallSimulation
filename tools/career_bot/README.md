# 커리어 봇 검증 도구 (2026-11-21, 오퍼 A·B·C + 이적 요청 채택 검증)

게임 코드는 건드리지 않는 검증 전용 도구다. 프로젝트의 `tools/career_bot/`에 두고 쓴다.
메인 화면(ui/center_panel)의 오퍼·팝업 처리를 화면 없이 같은 엔진 함수로 재현해 시즌을 진행한다.
기존 헤드리스 러너(tools/headless_runner.py)는 오퍼 창을 열지 않아 `generate_offers`가 한 번도 실행되지 않으므로,
내 선수 오퍼·이적 쪽 변경은 이 봇으로 검증한다.

## 파일
| 파일 | 역할 |
|---|---|
| prep_world.py | 시작 월드 만들기(원본 코드로 1회 → 원본·변경본이 같은 시작 상태에서 출발) |
| career_bot.py | 커리어 봇 본체(오퍼 창·재계약·판매추진·임대·고가 매각·국대 발탁 처리, 기록 bot_log.json) |
| analyze10.py | 10시즌 판정(지표 16개, 사전 고정 기준) |
| career10.py | 내 선수 커리어 관찰(이적 경로·오퍼 0개 구간·떠난 팀 보충) |
| pyqt_stub.py, renew_eq.py | 재계약 동등성 시험(메인 화면 코드를 가짜 PyQt로 실행 ↔ 봇 처리 비교) |

## 실행 순서 (모두 `PYTHONHASHSEED=0`)
```
python3 prep_world.py <원본코드폴더> 1 <월드1폴더>          # 시드 2도 같은 방식
python3 career_bot.py <코드폴더> <월드폴더> <출력폴더 s10_base_w1> 1 10   # 원본·확정본 × 시드 1·2 = 4런
python3 analyze10.py <s10_* 폴더들이 있는 폴더>
python3 career10.py <같은 폴더>
python3 renew_eq.py ui 0 out_ui.json <코드폴더> <월드폴더>   # bot / early 1 도 같은 방식, 결과 JSON 비교
```
- 동작 확인용 환경변수: `BOT_MAX_WEEKS=N`(N주에서 멈춤), `BOT_FORCE_ACCEPT=1`(수락 경로 시험, 본 실험에선 쓰지 않음).
- 같은 코드·같은 시드면 결과가 완전히 같다(AI 선수·경기·이적 기록·내 선수 해시 일치 확인).
- 1시즌 1런 약 150초, 10시즌 1런 약 31분(2코어에서 2런씩).

## 봇 규칙(원본·변경본 동일)
- 시작: 한국 국적 24세 ST, OVR 90(능력치 균등), 에이전트 B, 분데스리가 1부 팀 평균 중위 팀 입단(시드1 아우크스부르크, 시드2 우니온 베를린).
- 일정: center_panel `_get_match_for_day`를 소스에서 떼어 써서 1주 모드와 같은 일정(경기일·경기 다음날 휴식·훈련 기본값).
- 오퍼: 우선순위 1위 오퍼의 팀 평균 OVR ≥ 지금 팀이면 `reserve_join_transfer`로 수락, 아니면 전부 거절. 이적 요청은 쓰지 않음.
  OfferWindow 생성 때의 난수 소비(협상 횟수·계약 기간·기간 협상 횟수)를 화면과 같은 순서로 재현.
- 재계약은 협상 없이 수락(화면 코드와 동일함을 renew_eq.py로 확인 — 선수 상태 263칸·로그·meta·다음 난수 일치).
  판매추진·완전 영입·구단 임대·고가 매각·국대 발탁은 거절.
